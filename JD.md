# Job Description (JD)

## Senior Software Engineer

### Overview

We are seeking a highly skilled and experienced Senior Software Engineer to join our engineering team. The ideal candidate has strong expertise in designing scalable backend systems, distributed architectures, and cloud-native infrastructure. This role requires hands-on experience with microservices, real-time systems, API development, database optimization, and modern DevOps practices.

The successful candidate will collaborate closely with cross-functional teams, mentor junior engineers, and contribute to building high-performance systems serving millions of users.

---

# Key Responsibilities

## Backend & Distributed Systems Development

* Design, develop, and maintain scalable backend services and distributed systems.
* Build and optimize real-time data processing pipelines capable of handling high transaction throughput.
* Architect and implement event-driven microservices using modern backend technologies.
* Develop reliable APIs and integrations for internal and third-party systems.
* Ensure high availability, fault tolerance, and system reliability.

## Performance Optimization

* Optimize database queries, caching strategies, and application performance.
* Improve API response times and system scalability.
* Analyze bottlenecks and implement solutions for large-scale applications.
* Enhance real-time synchronization and collaborative system performance.

## Cloud & Infrastructure

* Deploy and manage cloud-native applications on AWS or Azure.
* Implement CI/CD pipelines for automated testing and deployment.
* Work with Docker and Kubernetes for containerization and orchestration.
* Utilize infrastructure-as-code tools such as Terraform.
* Monitor system health using observability tools and logging platforms.

## Collaboration & Leadership

* Collaborate with product managers, designers, and engineering teams.
* Participate in architecture discussions and technical decision-making.
* Mentor junior engineers and conduct code reviews.
* Establish and maintain coding standards and best practices.
* Contribute to continuous improvement of engineering processes.
